# Data-cleaning-and-Preprocessing--Task-1-
Task 1 of my AI &amp; ML Internship at Elevate Labs focusing on data cleaning and preprocessing using Python, Pandas, NumPy, Matplotlib, and Seaborn. This project includes handling missing values, encoding categorical data, feature scaling, and outlier detection.

Steps Performed:-

1-Imported and explored the dataset using Pandas to understand rows, columns, data types, and missing values.
2-Handled missing values by filling missing values in Age with median, Embarked with mode, and dropping Cabin due to excessive null values.
3-Encoded categorical features by converting Sex into numerical values and applying One-Hot Encoding on Embarked.
4-Standardized numerical features like Age and Fare using StandardScaler for better model performance.
5-Detected and removed outliers from the Fare column using Boxplot and IQR method.

Tools Used:-

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

Outcome:-

Successfully cleaned and transformed raw data into a structured format ready for machine learning models.
